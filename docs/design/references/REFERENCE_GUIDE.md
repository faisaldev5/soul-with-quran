# SoulWithQuran Design References

These screenshots and examples are visual inspiration only.

They must not be copied exactly.

Codex may study:

- Layout hierarchy
- Section composition
- Spacing
- Content grouping
- Typography proportions
- Image placement
- Interaction patterns
- Responsive ideas
- Visual rhythm
- Conversion flow

Codex must not copy:

- Brand colors
- Logos
- Written copy
- Images
- Icons
- Illustrations
- Exact component styling
- Proprietary visual assets
- Complete page layouts
- Brand-specific patterns

All implementations must remain consistent with:

1. `PROJECT.md`
2. `INFORMATION_ARCHITECTURE.md`
3. `DESIGN.md`
4. `ROADMAP.md`
5. `AGENTS.md`

SoulWithQuran’s approved colors, typography, logo, content, spacing system,
accessibility requirements, and brand personality always take priority over
the reference designs.

For every reference, Codex should identify:

- What is useful
- Why it is useful
- What should be adapted
- What should not be copied
- How it can be translated into the SoulWithQuran design system
