# SoulWithQuran Design Decision Sheet

**Version 1.0**  
Final creative direction for Google Stitch & Codex

# **1\. Brand Personality**

* Premium  
* Calm  
* Trustworthy  
* Warm  
* Modern  
* Minimal  
* Human  
* Educational  
* Structured

# **2\. Visual Direction**

* Clean layouts with generous whitespace  
* Modern educational aesthetic  
* Friendly without looking childish  
* Professional without feeling corporate  
* Light theme only

# **3\. Final Color Palette**

| Role | Color | Hex |
| :---- | :---- | :---- |
| Primary | Deep Navy | \#153B6D |
| Secondary | Soft Sage | \#7E9F8A |

| Muted | Gray | \#6B7280 |
| Success | Green | \#2E7D32 |

| Error | Red | \#C62828 |

# **4\. Typography**

* Heading: Plus Jakarta Sans  
* Body: Inter  
* H1 56 • H2 44 • H3 36 • H4 28 • H5 22 • Body 18 • Small 16  
* Weights: 700 / 600 / 400

# **5\. UI Decisions**

* 8px spacing system  
* 1200–1280px content width  
* 16px card radius  
* 12px input radius  
* Pill-shaped primary buttons  
* Soft shadows only  
* Lucide icon library

# **6\. Imagery**

* Real tutors and families  
* Natural daylight photography  
* Online learning scenes  
* Minimal illustrations  
* Avoid generic business stock photos

# **7\. Micro-interactions**

* 200–300ms transitions  
* Subtle button hover  
* Soft card lift on hover  
* Smooth accordion animation  
* Sticky navigation on scroll

# **8\. Design References**

* Apple — spacing, clarity, simplicity  
* Stripe — polished UI  
* Linear — typography and precision  
* Headspace — warmth and friendliness

# **9\. Google Stitch Brief**

Create a premium tutor-led Quran learning website using the above decisions. Focus on trust, readability, whitespace, elegant typography, subtle interactions, and a modern educational aesthetic. Avoid dark mode, excessive gradients, heavy Islamic ornamentation, or clutter. The homepage should feel welcoming, premium, and conversion-focused.
