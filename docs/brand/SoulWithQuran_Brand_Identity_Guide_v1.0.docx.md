# SoulWithQuran Brand Identity Guide

**Version 1.0**  
Concise branding guide for design, Google Stitch and development.

# **Brand Positioning**

Premium tutor-led online Quran learning for English-speaking families and adults. The brand should feel calm, trustworthy, modern, warm, minimal, and personal.

# **Brand Personality**

Trustworthy, Calm, Warm, Modern, Premium, Human, Educational, Structured, Minimal.  
Design keywords: Elegant, Spacious, Authentic, Timeless, Friendly, Confident.

# **Visual Direction**

Use generous whitespace, clean layouts, subtle shadows, soft rounded corners and authentic photography. Avoid clutter, excessive ornaments and loud gradients.

# **Color Palette**

Primary: \#153B6D (Deep Navy)  
Secondary: \#7E9F8A (Soft Sage)  
Accent: \#D6A64F (Warm Gold)  
Background: \#F8F7F4  
Surface: \#FFFFFF  
Text: \#2B2B2B  
Muted: \#6B7280  
Success: \#2E7D32  
Warning: \#D97706  
Error: \#C62828

# **Typography**

Headings: Plus Jakarta Sans  
Body: Inter  
H1 56, H2 44, H3 36, H4 28, H5 22, Body 18, Small 16\.  
Weights: 700 headings, 600 section titles, 400 body.

# **UI Style**

8px spacing system. Max width 1200–1280px. Radius: 16px cards, 12px inputs, pill buttons. White cards with soft shadows. Navy filled primary buttons and outline secondary buttons. Rounded outline icons.

# **Imagery**

Use authentic tutors, families, online classes, notebooks and natural daylight. Avoid generic corporate stock images. Minimal illustrations only where useful.

# **Google Stitch Brief**

Design a premium educational website with a calm modern aesthetic using this palette and typography. Focus on readability, whitespace, trust and conversion. Single light theme only.

# **Implementation Checklist**

Responsive-first, accessible contrast, reusable components, consistent spacing, SEO-friendly layouts, optimized performance, mobile-first navigation.
